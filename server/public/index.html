Capability set

Built like a checkpoint, not a captcha.

Staff drop a panel. Members open a private link. Umbrella decides. The server never has to guess.

01 · Binding

Global IP lock

If an IP is already verified to another Discord account, the second identity is denied. The check is global — the originating server does not matter.

02 · Perimeter

VPN & proxy denial

Commercial VPNs, datacenter proxies, Tor, and high-risk ranges are rejected before a role is ever touched.

03 · Control

Staff-owned logs

/setlogs points Umbrella at a channel. Every pass, VPN block, and collision is written there with a masked address.

Protocol

Four steps. No shared links.

Every member receives a URL minted only for them. Reusing someone else’s link does nothing useful — the token is bound to that Discord user.

01

Panel

An admin runs /panel. Umbrella posts the verification message and button.

02

Issue

The member clicks Verify and receives a personal, expiring URL.

03

Scan

The node reads the IP, rejects VPNs, and searches the identity database.

04

Grant

Same account on a known IP passes. A foreign account on that IP is refused. Role applied via /setverifyrole.

Command surface

Three commands. That is the kit.

CommandPurpose
/panel Sends the verification embed and button in the current channel.
/setlogs Sets the text channel that receives pass / deny logs.
/setverifyrole Sets the role granted when a member clears the gate.
